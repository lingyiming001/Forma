# Forma 开发里程碑

更新：2026-10-21。当前交付：0.6 开发预览，继续向商业 MVP 演进。

## 0.6 完成范围

- 单个 `.forma` 文档支持多个页面：新增 `DiagramDocument`（`pages: [Diagram]` + `activePageID`），复用 `Diagram` 作为单页模型，最小化渲染/导出/校验改动。
- 底部页签栏可添加、删除、重命名、复制及左右移动页面；复制页面重映射节点/连线/Panel/回收项全部 ID；页面级操作进入统一快照 Undo/Redo；至少保留一页。
- 文件格式升级 v3（`minimumReaderVersion` 3），v1/v2 单页文档自动迁移；备份归档、仓库与 FormaDocument 同步多页；侧栏/检查器标注“页面”。
- 画布网格由点阵改为主次分层线阵（次线 0.5pt、主线 1pt 每 5 格一根，对齐世界原点、随缩放自适应密度），明暗主题下网格线均清晰可见。
- 底部状态栏缩放百分比改为可编辑输入框，支持直接输入百分比（回车/失焦应用，夹取 5%–800%）。
- 基础图形扩充：箭头/三角形/六边形/平行四边形/注释；连接线支持独立线型（实/虚/点）与箭头（无/单/双），`DiagramEdge` 新增可选 `lineStyle`/`arrow`，未设置时由 `UMLRelation` 推导，旧文件无需升级即可解码。

## 0.5 完成范围

- 连接线增加视口包围盒裁剪，低缩放 UML 类图省略内部成员绘制，减少大图每帧工作量。
- 图层侧栏改为一次节点分组和 LazyVStack，并限制单次实体化数量，避免大量 Panel 时的 O(P×N) 扫描。
- 自动布局使用后台任务、防重入和 revision 校验；文档变化时放弃过期结果。
- PNG/PDF 离屏绘制和文件写入移出主线程，窗口显示统一的处理状态。
- 增加 2,000 节点布局及后台导出检查，作为卡顿风险的持续回归门禁。

## 0.4 完成范围

- 参考专业 Diagram 工具重做图形库：搜索、折叠分类、数量提示和持久化常用图形。
- 图形支持从侧栏直接拖放到画布，落点沿用吸附、Panel 归属、校验和 Undo 事务。
- 原生 Toolbar 增加撤销、重做、就地复制和移入回收箱，并根据历史与选区状态验证可用性。
- 增加专用图形库渲染检查及 Toolbar 快捷项检查；保留原有 macOS 原生窗口、侧栏和检查器结构。

## 0.3 完成范围

- 工作空间主页增加完整备份和恢复入口，输出单个 `.formabackup` LZFSE 压缩归档。
- 归档覆盖所有工作空间、活动文档、文件回收箱、名称和修改时间，并通过 SHA-256 验证完整性。
- 恢复前完成容量、版本、摘要和领域模型校验；暂存成功后再安装，避免验证失败产生半恢复状态。
- 恢复采用合并策略，工作空间标识冲突时重映射，不覆盖当前数据；备份格式暂不提供加密。
- 增加归档往返、回收箱保持、重复恢复冲突与损坏归档原子拒绝测试；中英文界面同步增加备份文案。

## 验证方式

`./scripts/verify.sh` 包含模块依赖检查、本地化资源检查、Swift Testing、Debug App 构建和原生 NSDocument／视图集成检查。最终次数、构建与截图记录在 `.agents/STATUS.md` 和 `.agents/test/`，不将本地 App 内检查称为完整鼠标、IME 或 XCUITest 验收。

专项回归包括：

- 画布平移前后，侧栏采样像素保持一致，并检查三层原生裁剪标志。
- 原生工具组进入可见 toolbar items，六个子项使用有效 NSImage；不依赖系统控制组的私有承载 view。
- 保存／重开／undo／redo／dirty 状态、逻辑窗口标题、界面语言切换后文档内容不变。
- Panel 与 UML 原生窗口、中文／英文设置窗口、工作空间主页和导出产物的渲染检查。
- 模型层覆盖成员和关系的 round-trip、旧格式、恢复依赖、文件冲突不覆盖、打开文件操作保护和并发启动默认空间只创建一次。

## 关键实现取舍

1. **Panel 为单层逻辑画框**，成员保留世界坐标；移动统一产生一次事务。画框不裁剪其子图形，画布必须裁剪。尚无嵌套 Panel／通用分组；页面为并列独立单元，尚无跨页引用。
2. **两个回收箱分别处理文档和页面元素**。文件位置是真实来源，不额外维护文档索引；工作空间回收箱提供全部恢复与确认后永久删除，页面回收箱仍无自动清空入口。
3. **工作空间仓储 actor 串行执行文件操作**；ensureWorkspace 在同一 actor 调用内查找／创建，防止多个窗口初始化产生重复默认空间。
4. **文档历史仍为不可变快照**，最多 100 次事务。大文件支持前必须改为稀疏补丁与字节预算。
5. **语言资源使用标准 .strings + Bundle.module**；SwiftUI / AppKit 共用资源，Domain 无本地化依赖。后续可迁移 String Catalog 而不改业务模型。
6. **系统文件对话框遵循 macOS 语言**，内部界面与菜单即时切换；图表名称、内容和已有模板不自动翻译。
7. **NSDocument 唯一协调原文档保存**，App 通过锁保护值快照；工作空间仓储只修改未打开的托管文件。原生 UndoManager 通知负责 dirty tracking，不能重复 updateChangeCount。
8. **UML 是表达级建模**，没有完整元模型、代码生成或数据库迁移校验；ER 当前使用实体字段和基数标签，不声称完整 Crow's Foot 约束编辑器。

## 工程与数据

- 宿主：App/main.swift、AppDelegate.swift、FormaDocument.swift、WorkspaceWindowController.swift、WorkspaceLibraryWindowController.swift、SettingsWindowController.swift。
- 业务：FormaApplication 的 DocumentSession／WorkspaceLibrary／AppPreferences。
- 存储：FormaDocumentIO 的 DocumentCodec／LocalWorkspaceRepository。
- 模型：DiagramPanel／RecycledElements／UMLRelation；Diagram 的 panels/recycleBin；节点的 panelID、attributes、operations、stereotype。
- 本地化：FormaLocalization/Resources/{zh-Hans,en}.lproj/Localizable.strings。
- 隐私清单按当前 app-only UserDefaults 与本地文件时间显示声明；依据 [Apple required reason API 文档](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)。不上传图表或工作空间数据。
