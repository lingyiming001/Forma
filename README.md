# Forma

让想法，清晰成形。使用 Swift、AppKit 和 SwiftUI 构建的 macOS 原生 Diagram 编辑器。

当前版本 **0.5 开发预览**：本地工作空间、压缩备份与恢复、可搜索图形库、大图响应优化、文件／图形回收箱、同页多个 Panel、UML 与企业架构图、设置及中英文界面。应用图标和蓝紫强调色参考用户提供的 `Logo.png`，原图保持不变。

## 运行

最低部署版本 macOS 14，当前开发包为 Apple Silicon。实机验证环境：macOS 26.6.2、Xcode 27.1、Swift 6.4；macOS 14／15 和 Intel 尚未进行实机回归。

```sh
./scripts/run.sh
```

也可以在 Xcode 打开 `Forma.xcodeproj`，选择 Forma scheme 运行。构建后的应用位于 `deploy/build/Forma.app`。安装到本机时，先退出 Forma，再运行 `./scripts/deploy-local.sh`；脚本安装 `/Applications/Forma.app`，将交付包保存为 `deploy/Forma.app.zip`，并移除构建目录中的应用副本。关闭窗口不会退出应用。

开发脚本生成本地未公证构建；生产签名、公证与完整 Sandbox 验收尚未完成，勿作为商业正式发布包分发。

## 工作空间

- 启动进入工作空间主页，支持创建、重命名、切换和搜索；图表默认按修改时间排列。
- 主页“新建图表”直接创建空白文档；模板在当前工作空间创建托管文件。
- 文件卡片菜单支持打开、重命名、跨工作空间移动、移入回收箱；回收箱可以恢复文档。
- 文档已在编辑器打开时，文件移动、重命名、移入回收箱会提示先关闭，避免覆盖窗口内未保存内容。
- 编辑器工具栏的四宫格按钮返回工作空间；检查器底部菜单“存入工作空间副本”将外部或未命名文档的独立副本存入当前工作空间，保留原文档。
- 工作空间用 Application Support 存储，开发包通常为 `~/Library/Application Support/Forma/Workspaces`；Sandbox 分发时由系统定位到应用容器。

```text
Workspaces/<workspace UUID>/
├── workspace.json              # 名称、标识和创建时间
├── Documents/<document>.forma/ # 活跃文档
└── Trash/<document>.forma/     # 可恢复文档，不是 Finder 废纸篓
```

文件位置是真实来源，没有容易失步的第二套文档索引；工作空间初始化在 actor 内原子执行，避免多个窗口重复创建默认工作空间。暂不提供云同步、账户或团队权限。

### 压缩备份与恢复

工作空间右上角的更多菜单提供“备份所有工作空间…”和“从备份恢复…”。备份前会提交并保存当前已打开的工作空间文档，然后输出单个 `.formabackup` 压缩文件，包含全部工作空间、活动图表、工作空间回收箱内容、名称和修改时间。归档使用 LZFSE 压缩，并保存 SHA-256 完整性校验；恢复前会验证文件类型、512 MB 上限、版本、校验值及所有图表模型。

恢复以合并方式执行：每个归档工作空间作为新工作空间加入，遇到已有标识会自动重映射，不覆盖当前内容。所有数据先写入暂存目录，验证和写入完成后再安装；损坏、截断或更高版本归档不会产生部分工作空间。备份没有加密，不应将含敏感图表的归档放到不受信任的位置。

## 画布与多个 Panel

- 基础图形、文字、精确命中、多选／框选、拖动、四角缩放、位置／尺寸／字号／配色、隐藏／锁定、对齐、剪贴板及 UndoManager。
- 双指平移／捏合缩放，空格临时抓手，网格与移动吸附；画布显式裁剪，平移和缩放不会覆盖侧栏。
- `P` 或工具栏虚线框创建 Panel。同一页面可有多个命名分区，图层面板按 Panel 展示其子图形。
- 拖动 Panel 标题会移动全部内容，调整 Panel 尺寸不会缩放子图形；没有嵌套 Panel。
- 拖动图形后按中心位置确定归属，也可以在检查器“所属分区”中调整。复制整个 Panel 会重建节点、分区及内部连线的标识。
- Panel 是组织分区，不是额外页面或独立视口；分区本身不裁剪溢出的子图形。画布视口始终裁剪。
- 双击／Return 使用原生 NSTextView 编辑，支持系统输入法；⌘Return 提交，Esc 取消。临时文字历史与文档历史分离。
- 连接线绑定节点并自动跟随；选中连线后可拖动两端圆点，将端点吸附到图形的其他边或边上位置（靠近边中点时吸附到中点）。端点位置随文件保存。树形布局按 Panel 分区执行，并扩展画框。循环／多父图会说明原因并保留原内容。

## 图形库与快捷操作

- 左侧“图形”页提供即时搜索，按基础图形和 UML／企业架构分类，可独立折叠。
- 右键图形可加入或移出“常用图形”，选择会通过 UserDefaults 跨启动保留，不写入图表文件。
- 图形既可单击后在画布放置，也可以直接拖到画布目标位置；拖放仍经过网格吸附、Panel 归属和文档 Undo 历史。
- 原生窗口工具栏新增撤销、重做、就地复制和移入回收箱。按钮根据 Undo 状态和当前选择自动启用，窄窗口由 macOS 管理溢出。

## 大图响应与防卡顿

- 画布只绘制视口相交的 Panel、节点和连接线；低缩放时省略 UML 类成员等细节，选中对象仍完整显示。
- 图层侧栏先一次性按 Panel 分组，再使用 LazyVStack 构建；单 Panel 最多展开 250 个节点、顶层最多 500 个节点、连接线最多 500 条，其余内容显示数量摘要，画布数据不受影响。
- 树形自动布局在后台任务执行，并显示不可重复触发的处理状态；计算期间若文档已变化，旧结果会取消，不覆盖新编辑。
- PNG/PDF 离屏绘制及原子写入转移到后台 executor，保留 PNG 40M 像素／16,384 边长上限，导出时主窗口可以继续响应。
- 单节点拖动时只定位被预览的元素，避免每帧遍历完整节点数组。当前验证包含 2,000 节点布局和后台导出回归。

## 两级回收箱

1. **工作空间回收箱**：卡片菜单将整个 `.forma` 文件移至工作空间 Trash，可单个或全部恢复；“清空回收箱”需二次确认后永久删除，打开中的文档会阻止清空。
2. **页面回收箱**：Delete 将图形、Panel、关联线作为一组保留在当前文件，点击编辑器左下角回收箱恢复；数据随保存重开保留。

页面删除和恢复均能撤销。恢复单项若依赖仍在回收箱的节点或 Panel，会说明原因并保持内容不变；“恢复全部”可恢复关联内容。

## UML 与企业图

内置十种模板：系统架构、业务流程、思维图、多 Panel 工作页、UML 类图、UML 用例图、UML 组件图、实体关系图、C4 系统上下文及空白画布。

- UML 类／接口支持构造型、属性与操作分区；检查器中每行一个成员，点击“应用成员修改”一次提交。
- 支持参与者、用例、组件、数据库、包等图形。
- 关系类型包括有向连接、关联、泛化、实现、依赖、聚合和组合，分别使用实线／虚线、普通箭头、空心三角及空心／实心菱形。
- ER 模板表达实体、PK／FK 字段和关系基数；C4 模板表达用户、系统与外部依赖。

这些是表达级图形建模能力，尚无完整 UML 元模型校验、序列图专用交互、代码生成或数据库 schema 校验。

## 设置与语言

`Forma → 设置…`（⌘,）提供：

- 语言：跟随系统、简体中文、English。界面和原生应用菜单即时切换，不改写已有文档、图形或用户输入的名称。
- 外观：跟随系统、浅色、深色。
- 启动是否进入工作空间；新窗口默认网格和吸附；PNG 导出 1×／2×。

新建模板使用当前语言，已有模板文档保留其内容。系统文件对话框由 macOS 的语言设置决定。资源集中在 `FormaLocalization/Resources/{zh-Hans,en}.lproj/Localizable.strings`，两种语言键集合及调用覆盖纳入脚本门禁；日期按选定界面语言显示。

## 文件与导出

原生 `.forma` 文件包包含 `manifest.json` 与 `document.json`；格式 **v2** 保存 Panel、回收记录、UML 成员和关系类型。可读取 v1，缺失的新字段默认空值；编辑保存后写入 v2，旧版应用不能读取 v2。打开 v1 本身不会主动重写文件。

NSDocument 管理保存、草稿、自动保存、另存及恢复到上次保存。非主线程读写使用不可变快照，URL 读取先检查大小和符号链接。PNG 及 PDF 共用绘制几何与排版，不输出网格、选中框或回收内容。

## 工程与验证

`App/` 负责 NSApplication、NSDocument、窗口和依赖装配；本地 SPM 包 `Packages/FormaKit` 有十个运行时模块：Geometry、Domain、Application、CanvasEngine、DesignSystem、WorkspaceFeature、DocumentIO、Interchange、CatalogInfrastructure、Localization。Domain／Geometry 不依赖 AppKit 或 SwiftUI。

```sh
python3 scripts/check-architecture.py
python3 scripts/check-localizations.py
swift test --package-path Packages/FormaKit
./scripts/verify.sh
./scripts/build.sh Release
```

Xcode 工程已提交；新增 `App/` 根目录 Swift 文件后运行 `python3 scripts/generate-project.py` 更新。生成器会重写宿主工程，手工改 build settings 时应同步修改生成器。

验证覆盖模型／兼容／Panel／回收箱／工作空间／本地化与导出，并用真实 NSDocument 检查保存点、撤销重做；原生视图检查覆盖画布裁剪、工具栏、菜单语言、设置及模板输出。产物统一位于 `.agents/test/`。Debug 的 `--verify` 入口直接验证应用内对象，不等同于完整 XCUITest、真实鼠标／IME 回归；远端 CI 尚未执行。

## 当前限制

仍是单页、单层 Panel，不支持通用分组／旋转、图片、组件实例、SVG／draw.io 导入、专业避障、专用思维树与多人协作。撤销使用最多 100 个不可变快照，稀疏补丁／字节预算、旁路恢复日志、故障注入及大型文档性能门禁待完成。自动保存覆盖已提交操作，尚在文本编辑器中未提交的内容不进入文档快照。

文档安全上限为 20 MB JSON、20k 图形（包含页面回收箱）、40k 连接线、1k Panel；这不是交互性能承诺。原始 Logo 版权、商标和正式应用标识需在对外发布前核验。

完整商业目标见 [架构方案](docs/Forma-产品设计与技术架构方案.md)，实际状态见 [开发里程碑](docs/开发里程碑.md)。
